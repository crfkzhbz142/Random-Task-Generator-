## Описание программы


**Random Task Generator** — это GUI‑приложение для генерации случайных задач с возможностью отслеживания истории и фильтрации. Программа позволяет:


* генерировать случайные задачи из предопределённого списка;
* добавлять новые задачи в список;
* просматривать историю сгенерированных задач;
* фильтровать задачи по типам (учёба, спорт, работа);
* сохранять историю и список задач в JSON‑файл;
* загружать данные из JSON‑файла;
* проверять корректность ввода при добавлении новых задач.

Приложение разработано на Python с использованием библиотек `tkinter` и `random`.


## Требования для запуска

Для работы программы необходимо:
* Python 3.8 или выше;
* стандартные библиотеки Python (`tkinter`, `random`, `json`, `os`) — не требуют отдельной установки.

## Примеры использования
### Сценарий 1. Генерация задачи
**Действия:**

- Нажмите «Сгенерировать задачу» несколько раз.

**Ожидаемый результат:**

- В списке истории появляются случайные задачи с указанием времени генерации.

- Отображается информация о количестве сгенерированных задач.

### Сценарий 2. Добавление новой задачи
**Действия:**

- В поле «Новая задача» введите: «Изучить документацию по API».

- Выберите тип «Учёба».

- Нажмите «Добавить задачу».

**Ожидаемый результат:**

- Задача добавляется в список доступных для генерации.

- Появляется сообщение: «Задача добавлена в список!».

### Сценарий 3. Фильтрация истории
**Действия:**

- Сгенерируйте несколько задач разных типов.

- В фильтре выберите «Спорт».

- Нажмите «Применить фильтр».

**Ожидаемый результат:**

- В истории отображаются только задачи типа «Спорт».

- Количество отображаемых задач соответствует фильтру.

### Сценарий 4. Сохранение и загрузка
**Действия:**

- Добавьте несколько новых задач.

- Сгенерируйте 5–10 случайных задач.

- Нажмите «Сохранить данные».

- Закройте и снова откройте приложение.

- Нажмите «Загрузить данные».

**Ожидаемый результат:**

- Восстанавливаются все добавленные задачи и история генерации.

### Сценарий 5. Обработка ошибок ввода
**Действия:**

- Оставьте поле «Новая задача» пустым.

- Нажмите «Добавить задачу».

**Ожидаемый результат:**

- Появляется сообщение: «Введите текст задачи!».

- Задача не добавляется.
